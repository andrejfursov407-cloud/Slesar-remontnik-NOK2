ТРЕНАЖЁР «СЛЕСАРЬ-РЕМОНТНИК НОК» — версия для Windows

Что подготовлено:
- исходный HTML-тренажёр встроен в комплект без изменения вопросов и изображений;
- создано оконное приложение Windows;
- приложение работает локально, интернет для самого тренажёра не нужен;
- предусмотрена сборка в один EXE-файл (HTML-файл остаётся рядом с EXE).

Как получить EXE:
1. Распакуйте архив в отдельную папку на компьютере Windows 10/11.
2. Установите .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
3. Дважды нажмите «СОБРАТЬ_EXE.bat».
4. После успешной сборки откройте папку «Готовая_программа».
5. Запустите «Слесарь-ремонтник НОК.exe».

Важно:
- Для отображения сайта используется Microsoft Edge WebView2 Runtime.
  На большинстве современных Windows 10/11 он уже установлен. Если приложение
  сообщит об отсутствии Runtime, установите его с официальной страницы:
  https://developer.microsoft.com/microsoft-edge/webview2/
- EXE и HTML-файл должны находиться рядом в одной папке.
- Сборка настроена для Windows x64.
